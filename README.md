# JavaScript Assignments and Mini Project

Contains the six assignments and capstone from the supplied JavaScript guide.

## Run
Open each assignment's `index.html` in a browser. Assignments 1 and 2 log to the browser Console because their instructions ask for logged output. Assignments 3–6 display their results on the page because the guide does not explicitly require console output for them. The capstone uses console output as the guide explicitly describes it as console-based.

For console output, press F12 and choose Console. No installation is needed.
