# Interactive Product Inventory & Analytics Dashboard

The supplied guide describes the capstone as a console-based application and labels the expected output as a console output simulation.

## Run
1. Open `index.html` in a browser.
2. Enter a product name and price when prompted.
3. Open Developer Tools (F12) and select Console to see the report.

The starting inventory contains Laptop ($800) and Mouse ($25). Enter Monitor and 150 to reproduce the sample inventory.
